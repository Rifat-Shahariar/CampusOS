# CampusOS — Frontend

Next.js (App Router) + TypeScript client for CampusOS.

See the [root README](../README.md) for setup and [docs/architecture.md](../docs/architecture.md)
for the frontend layout and responsive-design rules.

```bash
npm run dev --workspace frontend    # from the repository root
npm run build --workspace frontend
npm run lint --workspace frontend
```

Environment variables: copy `.env.example` to `.env.local` and fill it in.
